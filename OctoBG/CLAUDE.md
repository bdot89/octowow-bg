# OctoBG - notes for Claude Code

Written 9 Oct 2026. Platform rules are the same as WhoDidIt's CLAUDE.md (Lua 5.0, 1.12 widget API,
no `#` / `%` / string methods / `select` / `...` expressions, 32 upvalues, 200 locals).

## Layout
- `core/Core.lua` namespace `OctoBG`, saved variables (`OctoBGDB`, defaults merged), pcall'd event
  bus `B:On(event, fn, bgOnly)`, ticker `B:Every(sec, fn, bgOnly)`, internal messages `OBG_*`
  (`OBG_INIT`, `OBG_ZONE`, `OBG_LAYOUT`, `OBG_ACTIVE`, `OBG_ENEMY`), zone keys WSG/AB/AV/TG/ARENA.
  bgOnly handlers/tickers run only while `B.active` (in a BG/arena, layout mode, or world HUD on);
  events only they want are unregistered from the client otherwise.
- `core/Util.lua` GUID + DLL wrappers, panels (`U.Panel`, positions in `db.pos[key]` as TOPLEFT),
  `U.SendBG` (1/s, same text once per 4 s), `U.Alert`, `U.Rotate` (8-arg SetTexCoord).
- `core/Map.lua` world/map conversion, facing, calibration, landmarks, WSG describer.
- `core/Tracker.lua` enemy players by GUID.
- `modules/` Flags, Timers (spirit + objectives + start + AB prediction + big res), Sync (raid
  sharing + stealth callouts), Incoming, HUD (+ enemy list), TacMap, Options (+ slash commands).
- `media/*.tga` generated by `tools/MakeTextures.ps1` (white + alpha, coloured in game).

## Learned in game
- 9 Oct 2026: the tactical map blacked out at random. Regions sharing one draw layer have no set
  order in this client: the map tiles and the panel backdrop were both BACKGROUND and swapped.
  Anything that must stack (tiles / darkening / markers) goes on child frames with explicit
  SetFrameLevel (TacMap and HUD do this now).
- Map and HUD markers (user's choice, 9 Oct 2026): enemies = `tri.tga` class-coloured triangle,
  always full colour (line of sight not shown on the markers; the enemy list still has it), only
  stale positions fade (map to 50 %, HUD to 40 %); raid members = smaller round `pip.tga`; stealth
  marks = purple `badge.tga` ring + class `pip.tga`. All have black rims (RGB black survives
  SetVertexColor). `db.map.dim` darkens the tiles (`/obg dim 0-90`).
- Class colours (user asked for "a lot clearer", 9 Oct 2026): `U.ClassColor` returns `U.BRIGHT`
  (saturated; Shaman blue, since 1.12's RAID_CLASS_COLORS has Shaman = Paladin pink) while
  `db.markers.bright` is on, else the game's colours. `db.markers.size` scales HUD and map triangles.
- Confirmed working from the user's AB screenshot: the AB world state parse (prediction rows),
  spirit guide timers with landmark labels, EnemyCooldowns icons in the list, enemy distances
  across the map.

- Enemy pickup range is the server's visibility range: the client has no way to list or reach units
  the server does not send (no enumeration API in nampower / SuperWoW / UnitXP_SP3 / VanillaHelpers;
  checked their exported names). The user's AB screenshot showed enemies tracked at 351-424 yd.
  Tracker measures it per zone (`db.reach`, `/obg reach`; printed after each battleground).
- Distance CVars found in this install (strings in the binaries): `unitDrawDist` (WoW.exe,
  "Unit draw distance", default 300), `horizonfarclip` (default 2112), `farclip` (user has 3000,
  slider max 777), `NP_NameplateDistance` (nampower, NampowerSettings max 200), `NameplateRange`
  (SuperWoW, SuperAPI max 80). `/obg maxview` raises them, backs up to `db.viewBackup`, `off` restores.
  Config.wtf must not be edited while WoW runs (it is rewritten on logout).
- Stealth: Stealth/Prowl/Vanish/Shadowmeld ids (Spy's list) from SPELL_GO_OTHER and
  BUFF_ADDED_OTHER (arg3 = spell id) -> `Tracker.stealth` marks, ring grows at 5 yd/s for 20 s.
- Raid sharing (`modules/Sync.lua`, 9 Oct 2026, user asked to "use alliance members' map data"):
  addon messages prefix "OctoBG" on BATTLEGROUND (RAID/PARTY outside). P = enemy positions (own
  object list only, 6 per message, 1/s, round-robin), S/D = stealth start/end, G = spirit guide
  waves every 10 s (only waves this client measured: `g.own`), C = "I posted this stealth to /bg"
  (callouts wait a random 0.2-1.2 s so one client posts). Received enemies go through
  `Tracker:Remote` (never overrides a unit in the own object list; `u.remoteAt`, listed for 3 s).
  `/obg sync` lists who is sharing. Not verified in game yet: SendAddonMessage "BATTLEGROUND" on
  this server, and whether nampower GUID strings always start "0x00000000" for players (Pack
  falls back to the full GUID otherwise).
- Stealth: besides nampower, the combat log ("X gains Stealth." / "X performs Vanish.") marks
  enemies by name ("name:<name>" key, at the player's own position, class from the spell).
  `db.stealth.shout` posts callouts to /bg (asked first, off by default).
- Hidden enemies (user asked how to track invisible enemies, 9 Oct 2026): `T.STEALTH` also has
  Invisibility (3680 Lesser Invisibility, 11392 Invisibility, 4079 Gnomish Cloaking Device -
  spell ids from memory, NOT checked against this client's Spell.dbc yet; the combat log names
  catch them either way). `T.CLUE` Sap 6770/2070/11297 and Pick Pocket 921 on the player or a
  group member (`FriendPos` only accepts those) marks the caster GUID at the target; the log
  fallback keys it "sap:<target>". `T:Touch` re-pins a mark when a marked GUID hits someone
  (fires OBG_STEALTH with quiet = true: shared again, never called out again). Circle speed per
  kind: `KIND_SPEED` (Invisibility 7, Shadowmeld 1, else 5). Sync KINDS gained Invisibility, Sap,
  Pick Pocket (indexes 5-7; older clients ignore them). Sync Unpack only expands 8 hex digits.
- Timers panel (user: "make the bars clearer"): dark track under each bar, statusbar texture,
  white outlined labels (the AB score label was blue on a blue bar), owner shown as a 3 px strip,
  times in gold when close, "Res waves" header; the player's own nearest graveyard marked
  "(you)" (`S:Nearest` only counts the player's faction now). Every row posts its line to /bg
  on click.
- Open world: Map.lua carries all 125 zone bounds from WorldMapArea.dbc (`WORLD`); `M.world` is the
  current zone (looked up once per zone). HUD, list and map run there when `db.hud.world` is on.

## Rules kept
- Posting to /bg only from a button or Ctrl-click; automatic INC posts are off and confirmed
  through a StaticPopup first (`db.inc.autoPost`).
- Spy / EnemyCooldowns tables are only read.
- Eviction: tracker units (25 s missing, max 80), rejected GUIDs (20 s, wiped at 500), spirit
  guides (120 s missing, max 24), errors (30), everything cleared on zone change.
